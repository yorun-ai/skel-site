# 问题排查

## 找不到 `domain.skel`

目录模式要求在输入目录下直接放一个 `domain.skel`。skelc 只会读当前目录，不会递归进子目录。

## domain 或 import 不一致

确认所有文件声明了相同的 domain，import 放在顶层声明之前，生成命令中 `--skel-import` 的 key 使用的是完整 domain 名。

## 公开依赖报错

公开 service/event 引用的本地 data、enum、actor 或 resource 也需要标上 `pub`。要么缩小引用范围，要么显式公开依赖，不要绕过检查。

## 生成文件没有被清理

重新生成时，skelc 会删除带有生成标记、但已不再需要的文件。生成标记是文件顶部附近的
`Code generated by skelc. DO NOT EDIT.`。移除标记后，该文件会被视为
手写文件并得到保留；不过如果手写文件与本次生成文件同路径，生成时仍会被覆盖。

## 生成 Go 代码版本不兼容

检查 `skelc version`、生成的 `go.mod` 和应用使用的 Vine 版本。升级后重新生成，不要只手动改 require。

## 仍有问题？

保存默认输出的完整 JSONL 诊断，附上最小输入、命令、skelc 版本和平台信息，然后提 issue。
